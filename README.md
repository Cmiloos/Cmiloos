Hago sistemas de gestión para comercios chicos: stock, ventas, precios e historial.
Todos tienen la misma idea atrás: que los pueda usar alguien que no es técnico, que se
abran con doble clic y que los datos queden en un archivo que se pueda abrir con Excel.

## Proyectos

### [rustico-gestion](https://github.com/Cmiloos/rustico-gestion)

Sistema interno de un local: ventas de mostrador, stock de cada producto, aumentos de
precios e historial. Corre en la computadora del local y también se usa desde el celular
conectado al mismo Wi-Fi. La base de datos es una planilla de Excel con dos hojas, así que
se puede abrir y revisar sin entrar al sistema.

*Python · web app que corre local · Excel como base de datos*

### [vetgestion-academico](https://github.com/Cmiloos/vetgestion-academico)

Gestor de stock para una farmacia veterinaria: productos, ventas, aumentos de precios e
historial. Es una aplicación de escritorio con la interfaz en HTML y CSS, corriendo en su
propia ventana y sin barra del navegador. Guarda en un Excel local o en una planilla de
Google compartida entre varias computadoras, y se descarga como `.exe` para no tener que
instalar nada.

*Python · JavaScript · pywebview · Google Sheets*

## Herramientas

Python · JavaScript · HTML y CSS · Excel y SQLite como base de datos · empaquetado a `.exe` para Windows
