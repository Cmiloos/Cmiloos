Hola, soy Camilo.

Hice un par de sistemas para locales. De esos que se abren con doble clic y guardan todo
en un Excel, para que los pueda usar cualquiera.

### [rustico-gestion](https://github.com/Cmiloos/rustico-gestion)

Ventas de mostrador, stock y precios de un local. Corre en la compu del local y también lo
abrís desde el celular con el mismo Wi-Fi.

### [vetgestion-academico](https://github.com/Cmiloos/vetgestion-academico)

Lo mismo pero para una veterinaria. Es un `.exe`: lo bajás, doble clic y anda. Guarda en un
Excel o en una planilla de Google.

Están hechos con Python y JavaScript. Y eso.
